# Cascata do Chuvisqueiro — Riozinho, RS

Aplicação web editorial e bilheteria digital para a **Cascata do Chuvisqueiro** (Vale do Paranhana, Riozinho, RS), construída com **Vite.js**, **GSAP + ScrollTrigger**, **Lenis** e **Leaflet**.

## Desenvolvimento Local

```bash
npm install
npm run dev
```

## Build de Produção & Preview

```bash
npm run build
npm run preview
```

## Deploy na Vercel

O projeto já inclui `vercel.json` configurado para **Vite** (`npm run build` -> `dist/`):

```bash
npx vercel --prod
```

Ou conecte o repositório diretamente no dashboard da Vercel (Framework Preset: `Vite`).
